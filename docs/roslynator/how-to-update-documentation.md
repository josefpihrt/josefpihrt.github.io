# How to Update Documentation

## Code Analysis Reference

- Update analyzer documentation in [Analyzers.xml](https://github.com/dotnet/roslynator/blob/main/src/Analyzers.xml).
- Update refactoring documentation in [Refactorings.xml](https://github.com/dotnet/roslynator/blob/main/src/Refactorings.xml).

See the [metadata reference](category/metadata) for details.

## Static Files

You can also edit or add static files [here](https://github.com/josefpihrt/josefpihrt.github.io/tree/main/docs/roslynator).

## Generated Documentation

API reference, testing framework, and CLI docs are generated from source metadata.

See [how to generate documentation](how-to-generate-net-api-docs) for details.

## Publication

To publish, submit a [PR](https://github.com/josefpihrt/josefpihrt.github.io/pulls?q=is%3Apr+is%3Aopen+sort%3Aupdated-desc).
